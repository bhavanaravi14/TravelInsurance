# Travel Insurance Prediction

## 1. Project Overview
This project focuses on predicting whether a customer is likely to purchase travel insurance based on their personal details, income, travel history, and other relevant factors.

The objective is to build a machine learning classification model that helps identify potential customers.

## 2. Project Objectives
- Analyze customer information and travel behavior.
- Identify important factors influencing travel insurance purchases.
- Perform data preprocessing and exploratory data analysis.
- Build a classification model to predict insurance purchase decisions.
- Evaluate model performance using appropriate metrics.

## 3. Dataset Description
The dataset contains customer-related information with the following features:

- Age
- Employment Type
- Graduate
- Annual Income
- Family Members
- Chronic Diseases
- Frequent Flyer
- Ever Travelled Abroad
- Travel Insurance (Target Variable)

## 4. Tools and Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 5. Implementation Steps
1. Imported the required Python libraries.
2. Loaded and explored the dataset.
3. Performed data cleaning and preprocessing.
4. Conducted Exploratory Data Analysis (EDA).
5. Prepared features and target variables.
6. Split the dataset into training and testing sets.
7. Built a Random Forest Classification model.
8. Evaluated the model using classification metrics.

## 6. Model Evaluation
The Random Forest Classification model achieved approximately 84% accuracy on the test dataset.

Evaluation metrics included:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Classification metrics

## 7. Key Outcomes
- Identified customer characteristics associated with travel insurance purchases.
- Built a classification model to predict customer purchase decisions.
- Evaluated model performance using multiple classification metrics.
